# 편집 기준 — 기본 틀(내 기준으로 고쳐 쓰기)

> 검수 에이전트가 이 파일을 체크리스트로 그대로 읽음. 항목 앞의 [필수] · [권고]가 검수 지적의 등급이 됨.
> 〔내 기준〕 자리는 채우거나 지우고, 맞지 않는 줄은 고치거나 지움. 항목을 더해도 됨.

## 1. 표기 — 국립국어원 한글 맞춤법 · 표준어 규정 · 외래어 표기법
- [필수] 맞춤법 · 띄어쓰기는 국립국어원 규정을 따름 — 규정과 다르게 쓰는 것은 〔내 기준〕
- [필수] 외래어 · 외국 인명 · 회사명은 외래어 표기법과 용례를 따름 — 원어 병기는 〔내 기준: 첫 등장 때만?〕
- [권고] 같은 낱말은 글 전체에서 한 가지로 표기(아래 6의 통일표)

## 2. 문장 — 교열
- [필수] 주어와 서술어의 호응 · 수식 관계가 분명함
- [권고] 한 문장의 길이 〔내 기준〕
- [권고] 번역 투를 줄임 — '~에 대한', '~을 통해', '~되어지다', '~적' 겹침 〔내 기준으로 목록 고치기〕
- [권고] 같은 어미 · 같은 접속어가 연달아 세 번 이상 나오지 않음

## 3. 윤문 · 문체
- [필수] 문체 샘플과 어긋나는 종결 어미 · 인칭 · 호칭이 없음 〔내 기준〕
- [권고] 단락의 첫 문장이 단락의 주장을 말함 〔내 기준〕
- [권고] 〔내 기준: 피하는 표현 · 즐겨 쓰는 구성〕

## 4. 숫자 · 단위 · 날짜
- [필수] 날짜 표기 〔내 기준: 2026. 10. 6. / 2026년 10월 6일 중 하나〕
- [필수] 숫자와 단위의 띄어쓰기 · 천 단위 쉼표 〔내 기준〕
- [필수] 퍼센트와 퍼센트포인트를 구분함

## 5. 인용 · 출처
- [필수] 직접 인용은 따옴표와 출처 번호를 달고, 원문과 글자 단위로 같음
- [필수] 간접 인용 · 수치에도 출처 번호
- [필수] 한 출처에서 옮겨 오는 분량 〔내 기준: 예 직접 인용 두 문장 이내〕
- [필수] 출처 표기 형식 〔내 기준: 예 발행 주체(발행일), 「제목」, 주소, 열람일〕
