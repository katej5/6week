## 무엇을 해결하려고 만들었나

글 한 편을 쓸 때마다 이 일을 모두 손으로 했습니다.

- 사람들이 관심 있는 주제인지 가늠하기
- 원문과 출처를 찾아 열어 보고 인용·수치를 대조하기
- 내 말투로 다시 고치기
- 이미지 만들기
- 편집 기준으로 검수하기

한 편에 하루 이상 걸렸습니다. 그래서 **단계를 쪼개고, 각 단계의 결과를 파일로 남기고,
사람이 정해야 할 자리에서는 반드시 멈추도록** 만들었습니다.

## 어떻게 움직이나 — 8단계

| 단계 | 하는 일 | 결과 파일 |
|---|---|---|
| 1 | 기획 — 독자·핵심 메시지·질문·목차·핵심 주장(C번호) | `01_기획.md` |
| 2 | 검색 관심도 — 웹 검색으로 간접 판단(N·M·Q 숫자) | `02_관심도.md` |
| 3 | 원문 조사 — 1차 원문을 **직접 열어** 발행일·확인 위치까지 기록 | `03_원문.md` |
| 4 | 출처 신뢰 — A/B/C 등급을 매기고 주장별 충족 여부 판정 | `04_출처.md` |
| 5 | 집필 — `raw/문체샘플/`을 근거로 문체 메모를 먼저 쓰고 집필 | `05_초고.md` |
| 6 | 이미지 — 수치가 있으면 SVG 도표, 없으면 개념도 / 사진형은 프롬프트만 | `06_이미지/` |
| 7 | 검수 — 만든 과정을 모르는 서브에이전트가 지적 목록을 돌려줌 | `07_검수.md` |
| 8 | 저장 — 최종본 + 게시 승인 요청 | `08_최종.md` |

### 핵심은 "멈추는 것"입니다

이 파이프라인의 목적은 빨리 끝내는 게 아니라, **사람이 판단해야 할 자리를 건너뛰지 않는 것**입니다.
멈춤은 세 종류입니다.

- **[자료 부족]** — 원문을 못 열었거나, 출처가 기준에 미달하거나, 문체 샘플이 2편 미만일 때
- **[사람 판단]** — 관심도가 '낮음'이거나, 검수 2회차에도 `[필수]` 지적이 남았을 때
- **[게시 승인]** — 8단계의 끝. **게시는 언제나 사람이 직접 합니다**

멈출 때마다 `진행상태.md`에 *어디서 · 왜 · 무엇을 해 주면 이어 가는지*를 적습니다.
그래서 중간에 끊겨도 그 파일 하나만 읽으면 이어 갈 수 있습니다.

### 근거 기준

- `[사실]` 주장마다 **A 1개** 또는 **서로 독립된 B 2개** 가 있어야 통과
  - **A** 1차 원문(법령·고시, 정부·공공기관 자료, 공식 문서, 논문 원문)
  - **B** 원문·취재원을 밝힌 언론·전문 매체 기사, 연구기관·로펌 해설
  - **C** 개인 블로그·커뮤니티·위키·AI 요약 → **근거로 쓰지 않고** 원문을 찾는 실마리로만
- 같은 보도자료를 받아 쓴 두 기사는 독립이 아니라 하나로 셉니다
- 출처마다 **주소 · 열람일 · 확인 위치**가 있어야 하고, 하나라도 비면 그 출처는 쓰지 않습니다
- 사실(제품·수치·현황)은 열람일 기준 **6개월 이내**, 법령은 **현행 여부**를 확인합니다

자세한 기준은 [`출처등급.md`](.claude/skills/writing-pipeline/references/출처등급.md)에 있습니다.

## 써 보려면

[Claude Code](https://claude.com/claude-code)에서 이 폴더를 열고:

```bash
# 새로 시작
/writing-pipeline raw/주제카드_내주제.md

# 멈춘 지점부터 이어 가기
/writing-pipeline out/2026-10-06_생성형AI-표시의무
```

시작하기 전에 `raw/`에 세 가지를 넣어야 합니다.

1. **주제 카드** — [`raw/주제카드_양식.md`](raw/주제카드_양식.md)를 복사해서 채웁니다.
   필수 칸은 주제·매체·분량이고, 독자와 핵심 메시지를 비우면 에이전트가 `〔제안〕`으로
   적은 뒤 **사람이 확정할 때까지 멈춥니다**.
2. **문체 샘플 2편 이상** — `raw/문체샘플/`에 **이미 공개된 본인 글**을 넣습니다.
   2편 미만이면 5단계에서 멈춥니다.
3. **편집기준** — `raw/편집기준.md`의 `〔내 기준〕` 칸을 채우면 검수가 세집니다.

멈춤 규칙이 실제로 지켜졌는지 기계적으로 확인하려면:

```bash
python out/검증_멈춤규칙.py
```

## 읽으시는 분께 미리 알려 드릴 것

### `.claude/settings.json`의 deny는 보안 경계가 아닙니다

```json
"deny": ["Edit(raw/**)", "Bash(rm *)"]
```

`Bash(rm *)`는 **실수 방지용**입니다. `rm -rf x`는 막지만
`find . -delete`나 `python -c "shutil.rmtree(...)"` 같은 건 걸리지 않습니다.
이 설정을 복사해 가실 때 "삭제가 막혀 있다"고 믿지 마세요.

### 저장소에 일부러 넣지 않은 것

[`.gitignore`](.gitignore)가 아래를 막고 있습니다.

- **문체 샘플 본문** — 다른 저자의 출간 도서 발췌라 저작권상 올리지 않았습니다(`_안내.md`만 올림)
- **초고 이전판** — 남의 문체로 쓴 비교용 판
- **PDF · 이미지 · 화면 캡처** — 저작권과 개인정보가 찍히기 쉬워서
- `.env` · `*.key` · 이름에 `개인정보`·`실명`·`내부자료`가 든 파일

### 라이선스 범위

이 저장소는 [MIT](LICENSE)입니다. 다만 **코드와 글이 섞여 있습니다.**

- `.claude/`, `out/검증_멈춤규칙.py`, 각종 양식·규칙 → MIT로 자유롭게 쓰셔도 됩니다
